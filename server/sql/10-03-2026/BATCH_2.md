# Second batch — 50 additional templates

These are new standalone PostgreSQL insert files for user **1**. Each can be
copied in its entirety into the Railway query editor, just like the original batch.
They include curated tags and complete search text, set `is_official_template` to
TRUE, and use database-generated IDs. Migration `c31d82ab690f` is required.
Each execution inserts another resume; it does not update an existing one.

The original 50 SQL files remain byte-for-byte unchanged. New approaches include
full black pages, right-side identity panels, numbered headings, warm reading
columns, dark skills footers, and project showcase sidebars. All content is fictional.
